# 红薯收纳 · 小红书、抖音与 X — v1.5.1

## 使用与更新

已安装本目录旧版：在 Edge 的 edge://extensions 找到“红薯收纳”，点击重新加载。如果出现新增 X/twitter.com 及媒体站点权限提示，按浏览器提示确认启用，然后刷新已经打开的网站页面。

新安装：将 ZIP 完整解压到固定目录，打开 edge://extensions，开启开发人员模式，点击“加载解压缩的扩展”，选择直接包含 manifest.json 的文件夹。不要从 ZIP 内直接加载，不要删除或移动已加载的目录。

## X 首页下载

在 https://x.com/home?lang=zh 正常登录并浏览。每条能识别编号的帖子下方会出现粉色“下载本帖全部素材”按钮，点击哪一条就下载哪一条，不跳转。帖子详情页右下角固定显示当前主帖按钮，按地址栏中的帖子编号识别，不依赖页面时间链接。详情页切换帖子后，按钮会跟随当前帖子更新。可以同时启动多个帖子，各自显示进度并提供停止、重试、打开文件夹。

保存该帖图片、页面提供的 MP4 视频及视频封面。图片优先请求原尺寸版本；视频优先使用页面提供的高码率 MP4。X 动图若提供 MP4，则保存 MP4 和封面，不伪造成 MOV 或苹果原生实况。当前帖明确附带的复用视频也会保存；独立引用帖、回复、头像、推荐帖的素材不自动混进当前帖子。如需引用帖素材，请打开该帖子再下载。

本版本从正常页面已加载的帖子数据中读取素材，并在数据缺失时尝试读取该帖可见图片。只有可见图片时会明确提示可能不完整。不会主动扫描账号全部历史帖子，不请求私信接口，不绕过登录、验证或访问限制。文本帖、外链卡片、仅 HLS 流、直播、加密或不可访问媒体可能没有可保存素材，页面会显示原因。网页改版可能需要更新适配。

## 保存规则

每帖目录：博主ID_北京时间日期_时间_文案摘要_帖子短ID。
X 优先用作者的 @用户名（screen_name，不加 @），缺失时使用账号数字 ID。文案摘要最多 54 字符，文件名中的 Windows 非法字符会替换。

- 图片/：PNG 图片、封面，以及小红书/抖音的 Live 静态图。
- 视频/：普通 MP4 和 X 提供的动图 MP4。
- MOV/：小红书/抖音页面可获取且本插件支持转换的 Live 动态视频。

每张 PNG 最多 3,000,000 字节；必要时按比例缩小尺寸。文件大小限制不代表无损保持原图分辨率。图片先获取源素材再压缩，因此无法直接减少源文件下载流量。单文件网络读取上限 512 MB；图片转换上限 8000 万像素。已下载的旧文件不自动修改。

每帖最多同时处理 3 个素材，多帖可以同时运行；图片转换最多同时 2 张。文件按 Edge 的默认下载目录保存，不打开新标签页。不生成 JPG、文案 TXT 或下载报告。

PNG 不能恢复原素材已经损失的画质。平台水印若已烙进素材不会自动消除，不能保证所有资源无水印。小红书/抖音 Live 的 PNG＋MOV 不保证苹果相册识别为原生 Live Photo；未暴露动态地址或不支持的编码会提示失败。

## 故障提示

安装或更新后必须刷新网站页面，以重新加载按钮和素材监听。看到“Extension context invalidated”时刷新页面；不要继续使用旧页面的按钮。

若 X 帖子数据未读取到，正常刷新 X 页面、等待帖子加载后再操作。完整媒体没有读取到时，不把“保存了可见图片”当作全部素材下载完成。

抖音当前包含预加载数据、网络响应和已渲染页面组件三种读取方式。用户此前报告的部分抖音页面仍未完成线上验证，不能据此承诺全部作品可用。

## 权限与数据

使用 downloads 保存文件、storage.session 保存临时任务、scripting 读取当前作品、offscreen 在后台转换图片。站点范围见 manifest.json，包括三个平台及对应素材 CDN。媒体直接从平台 CDN 获取；不使用第三方解析服务，不读取或发送账号 Cookie 和密码。

X 页面缓存最近最多 100 条接口中已返回的帖子的媒体、作者、时间与文案，关闭页面后清除；仅对列出的普通帖子接口监听，不监听私信。点击下载后只处理对应编号的帖子。

## 验证范围

1.5.1 在独立 Edge 测试配置中加载扩展，用模拟首页、详情页和素材响应验证完整链路：帖子按钮 → 页面提取 → 后台处理 → 真实 chrome.downloads 文件保存。共保存 7 张 PNG 和 4 个 MP4，按四位测试作者分别建目录，点击下载没有跳转。全部 PNG 经 Pillow 独立解码，大小不超过 3 MB；首页及带引用帖详情页的 MP4 与源测试视频字节一致。

详情页回归场景包括：主帖没有时间链接，只有引用帖时间；保存主帖明确附带的复用视频及封面，不下载引用帖的独立素材；页面不刷新就切换帖子，精确选择新帖；没有接口缓存时从渲染组件读取目标帖；返回首页后恢复帖内按钮。

另外验证了：严格匹配首页选定帖子、引用帖隔离、图片/视频/封面提取、动图保存 MP4、码率排序、仅 HLS 提示、页面组件与可见图片回退、错误反馈、抖音与小红书回归测试。

以上隔离测试使用构造帖子和本地素材，并非真实帖子录制。用户提供的 https://x.com/HoodyLiu/status/2104528042681143692 尚未完成线上端到端验证：浏览器连接失败，公开网页读取也未取得帖子数据。不能把隔离测试当作该帖子或全部真实帖子可下载的保证。
