# 红薯收纳 · Edge 插件 v1.3.1（按格式归类）

## 保存位置
每个帖子仍按“博主 ID＋发布时间＋文案摘要”建立总文件夹。所有图片（含 Live 静态图、普通图片及封面）集中放在“图片”内；所有 Live MOV 集中放在“MOV”内。普通 MP4 视频放在“视频”内。不再为每张 Live 建立单独文件夹。

```text
帖子文件夹/
  图片/
    live_001_短码.png
    live_002_短码.png
    image_003.png
  MOV/
    live_001_短码.mov
    live_002_短码.mov
  视频/
    video_001.mp4
```

PNG 和对应 MOV 保留相同文件名，方便对应；不生成 JPG、报告或文案文件。PNG＋MOV 不保证苹果相册识别为原生实况。旧下载文件不会自动移动或删除。

## 从旧版更新
如果已安装本目录中的旧版：在 `edge://extensions` 找到“红薯收纳 · 本帖素材下载”，点击卡片上的重新加载按钮，然后刷新小红书帖子。新增的 offscreen 权限用于后台转换图片，不会打开新页面。若 Edge 提示扩展已停用，请按浏览器提示确认后启用。

## 安装（无需上架商店）
1. 将 ZIP 完整解压到固定文件夹，保留全部文件。
2. 在 Edge 地址栏输入 `edge://extensions`，打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择直接包含 `manifest.json` 的文件夹。
4. 刷新已经打开的小红书页面。建议在 Edge 扩展菜单中将本插件固定到工具栏。

## 使用
打开具体的小红书帖子，点击右下角“下载本帖全部素材”，也可点击工具栏插件图标。
点击后直接在后台下载，不跳转、不打开新标签页。右下角按钮上方显示下载进度和结果，支持“停止下载”“打开文件夹”和“重试未完成素材”。同一个后台任务重试时，已完成素材不会再次下载。支持多个帖子同时下载：启动一个帖子后，可以打开其他帖子继续点击下载。各帖子独立保存和显示进度，停止一个不会停止其他帖子。每帖最多同时处理 3 个素材；全局最多同时转换 2 张图片，以控制内存占用。

默认保存在 **Edge 默认下载目录** 下，格式为：
`博主ID_发帖日期_发帖时间_文案摘要_帖子短ID/`

内部仅包含“图片”“MOV”“视频”等素材子文件夹，不生成报告或单独的文案文件。
图文帖图片按帖子顺序编号；Live 的 PNG 和 MOV 分别在“图片”和“MOV”文件夹中，共享编号和短码。视频帖 imageList 中提供的封面也会保存。
博主 ID 优先使用页面数据中的 redId，否则使用用户主页 ID（userId），不是昵称。
发布时间使用北京时间；未知时明确标记。为避免 Windows 路径过长，文案截取前 54 个字符，不另存文案文件。末尾附帖子 ID 后六位以降低同名冲突；已有文件由浏览器自动添加序号。

如果 Edge 为每个文件弹出保存窗口，请在 `edge://settings/downloads` 关闭“每次下载时都询问我该做些什么”或相应的逐次询问选项。插件使用浏览器默认下载目录，不能未经选择写入任意磁盘位置。可以在 Edge 设置中改变默认下载目录。

## 下载速度
每帖 3 路并行，保存完成检测间隔由 1.5 秒缩短到 0.3 秒。大 PNG 按原文件大小预估缩放尺寸，减少完整尺寸的重复编码。速度提升取决于网络、素材服务器和电脑性能，未承诺固定倍数。3 MB 是本地保存上限：仍需先获取源素材再压缩，因此不会直接降低原图网络传输量。已下载的旧文件不会自动重新压缩。

## 高清、PNG 和无水印的准确含义
- 图片优先请求原始素材地址，并将实际图片解码为 PNG，不是只改扩展名；每张 PNG 最大 3,000,000 字节（3 MB）；超出时按比例缩小尺寸，直到符合大小限制，不放大。小于限制的原始 PNG 直接保存。
- 默认关闭“页面显示图”回退。高清候选全部失败时明确显示失败，不静默保存缩略图。页面图可能被压缩或带水印。
- 仅从页面可获得的媒体信息构建候选地址。视频优先原始 key，否则按分辨率和码率排序尝试视频流。原始 key 不可用时可能使用较低清晰度流。
- **无法保证任何帖子都高清无水印，也不自动识别或修复烙在像素里的水印。** PNG 不会恢复已损失的画质；清晰度上限取决于服务器提供的资源。
- 普通视频保存为 MP4。Live 的 PNG 和 MOV 分别集中保存到“图片”和“MOV”文件夹；详细限制见上面的 Live 文件说明。
- 当前提取主帖素材，不下载评论区图片、推荐帖、未加载/未授权资源；不包含 OCR、自动扫描多帖或 ZIP 导出。这些截图功能不是本版的功能承诺。
- HLS、DRM、不可访问或已过期地址、未暴露动态地址的 Live 会失败或显示缺失提示。不会绕过登录、验证码或访问限制。
- 单文件上限 512 MB，图片转换上限 8000 万像素。PNG 转换需使用内存，超大图片仍可能受设备内存限制。

## 权限与隐私
只访问小红书和 xhscdn 媒体域名；使用 downloads 保存文件、scripting 读取当前帖子的页面数据、storage.session 临时保存任务。
offscreen 权限用于无可见标签页的 PNG 转换和媒体处理。无第三方下载服务、统计、广告、外部脚本和 cookie 读取权限。媒体请求发送至小红书媒体服务器。
在已登录的小红书页面使用现有可见数据，不额外要求账号密码；页面要求登录时仍需正常登录。
仅保存您有权使用的素材，尊重作者的使用授权。

## 故障排查
- 不显示按钮：确认网址为 `www.xiaohongshu.com` 的具体帖子路径；安装或更新后刷新页面。
- 无法读取：等待帖子内容完整显示，刷新后重试。网站更新页面结构可能需要更新插件。
- HTTP 403/404：回到原帖刷新，重新创建任务以更新地址；未完成项可重试。不要持续高频操作。
- 文件不在预期目录：检查 Edge 的下载位置与其他下载类扩展；“打开文件夹”定位第一个成功文件所在目录。
- 下载期间请保持 Edge 运行。关闭浏览器、重载扩展可能中断任务；重启浏览器会清除临时任务。后台被浏览器回收后，按钮会提示重试；新建任务可能再次保存已有文件。
